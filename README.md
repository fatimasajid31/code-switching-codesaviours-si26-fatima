
# Code Switching NLP | Code Saviours SI-26 | Fatima Sajid
## Project Overview
This project focuses on collecting and labeling a Roman Urdu–English 
code-switching dataset, where sentences naturally mix both languages 
as commonly used by Pakistanis in everyday text (social media, chats, 
comments).

## Roll Number
2023-BS-CS-197

## What This Repo Contains
- `SI-Week6-Fatima.ipynb` — Colab notebook for dataset labeling
- `dataset.csv` — labeled dataset (word-level URD/ENG/MIX tags)

## Dataset
- 200 real code-switched sentences
- Collected from Twitter/X, Reddit (r/pakistan), YouTube comments, 
  WhatsApp messages, and Facebook public pages
- 1357 total word entries, labeled as:
  - `URD` — Roman Urdu word
  - `ENG` — English word
  - `MIX` — word blending both languages
